# Community reports

Each file here is a report from the self-test issue (#2) that the maintainer
has checked. It is named after the issue, `<N>.json`, and holds the output of
`zark selftest certificate` for the report in that issue. The matrix page
shows its rows as "Community report #N", linked to the issue.

These files do not change what `zark selftest status` says: zark's coverage
reads only `certificates/selftest.json`.

To add one, see "Publishing a community report" in `docs/TESTING.md`.
